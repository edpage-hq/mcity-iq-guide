# Communications et ressources

Ouvert au PDG et au Pôle Support Partenaires & Clients.

## Communications

Une communication est une annonce publiée dans l'intranet, visible dès son
enregistrement.

1. **Administration → Communications → Nouvelle communication**.
2. Saisissez le **titre** et le **message**, et choisissez la **langue de
   rédaction** (anglais ou français).
3. Choisissez les **destinataires** :

   | Destinataires         | Qui la reçoit                                                                      |
   | --------------------- | ---------------------------------------------------------------------------------- |
   | Tout M'City           | Tous les comptes                                                                   |
   | Produit               | Les comptes dont le périmètre couvre le produit                                    |
   | Zone                  | Les comptes à qui la zone est attribuée, ou dont un bureau est dans la zone        |
   | Bureau                | Les comptes à qui le bureau est attribué (RH et Finance couvrent tous les bureaux) |
   | Département           | Les comptes rattachés au département                                               |
   | Poste                 | Les comptes qui ont ce poste                                                       |
   | Destinataires choisis | Les comptes sélectionnés                                                           |

4. Choisissez une ou plusieurs **cibles** : un compte reçoit la communication si
   son affectation correspond à au moins une d'elles. La direction (PDG et pôles)
   couvre tous les produits, zones et bureaux.
5. **Publier**.

Les destinataires sont prévenus par une [notification](../notifications). Une
communication peut être modifiée ou supprimée par ceux qui publient ; la
supprimer la retire de l'intranet de tous ses destinataires.

## Ressources partagées

**Administration → Ressources** gère les documents, procédures, notes, contacts
et liens de l'intranet.

1. **Nouvelle ressource**.
2. Choisissez le **type** et saisissez le **titre** et le **texte**, en anglais et
   en français.
3. Selon le type :
   - document : joignez le **fichier** (PDF, bureautique, texte ou image, 2 Mo au
     plus) ;
   - lien : saisissez l'**adresse du lien**.
4. **Produit** : laissez **Général (tout M'City)** pour une ressource visible de
   tous, ou choisissez un produit actif pour la réserver aux comptes dont le
   périmètre le couvre. Elle apparaît alors aussi dans l'espace du produit.
5. **Créer la ressource**.

Les comptes concernés sont prévenus. Supprimer une ressource supprime aussi son
fichier, définitivement. Un fichier n'est téléchargeable qu'après vérification du
périmètre du lecteur.
