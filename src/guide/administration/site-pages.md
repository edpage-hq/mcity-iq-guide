# Pages du site

**Administration → Pages du site** modifie le contenu du site public, sans
développement. Ouvert au PDG et au Pôle Support Partenaires & Clients.

## Les pages

| Page                                                | Contenu                                                                                               |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Général                                             | En-tête et pied de page : nom, accroche, identité légale, adresse, e-mail, téléphone, réseaux sociaux |
| Accueil                                             | Titre, introduction, piliers, sections produits et zones, appels à l'action, questions fréquentes     |
| Qui sommes-nous                                     | Vision, mission, valeurs, ancrage régional, identité légale                                           |
| Nos produits                                        | Introduction de la liste des produits, carte « Prochain produit »                                     |
| Nos zones                                           | Approche, méthode, note sous les zones                                                                |
| Prestations, Partenaires                            | Éléments, étapes, types de partenariats                                                               |
| Presse & kit média                                  | Présentation, chiffres, éléments de langage, logo, kit média, contact presse                          |
| Carrières                                           | Culture, offres d'emploi, comment postuler                                                            |
| Contact                                             | Texte au-dessus du formulaire, message de confirmation                                                |
| Mentions légales, Politique de confidentialité, CGU | Sections du texte, date de mise à jour                                                                |

Les landing pages des produits ne sont pas ici : leur contenu se saisit sur la
fiche du produit, dans le [registre](./registry#enregistrer-un-produit).
La page « Nos zones » liste les zones qualifiées du registre.

## Modifier une page

1. Ouvrez la page dans la liste. La liste indique la dernière modification et son
   auteur ; **Voir sur le site** ouvre la page publique.
2. Choisissez la **langue d'édition**. L'anglais est nécessaire pour qu'un texte
   s'affiche ; le français reprend l'anglais s'il est vide.
3. Modifiez les champs. Dans une liste (piliers, offres, questions…), ajoutez,
   retirez ou réordonnez les éléments.
4. Enregistrez.

La modification est en ligne immédiatement et inscrite au
[journal d'administration](./logs).
