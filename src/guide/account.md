# Mon compte

Ouvrez le menu de votre nom, en bas à gauche, puis **Paramètres**. Les
paramètres comptent cinq onglets : Profil, Sécurité, Notifications, Apparence et
Langue.

## Profil

Modifiez votre nom et votre adresse e-mail, et ajoutez une photo de profil.
Changer d'adresse e-mail demande de vérifier la nouvelle par le lien reçu.

Votre poste, votre périmètre et vos accès ne se modifient pas ici : ils relèvent
de l'administrateur général.

## Sécurité

### Mot de passe

Saisissez le mot de passe actuel, puis le nouveau (12 caractères au moins par
défaut). Changer de mot de passe oublie tous vos appareils mémorisés.

### Application d'authentification

1. **Activer la 2FA**, puis confirmez votre mot de passe.
2. Scannez le code QR avec votre application (ou saisissez la clé de
   configuration).
3. Saisissez le code à 6 chiffres affiché par l'application.
4. Conservez les **codes de récupération** dans un gestionnaire de mots de passe :
   chacun permet une connexion si vous perdez votre téléphone, une seule fois.

Une fois l'application active, c'est elle qui vous donne le code à la connexion,
à la place de l'e-mail. **Désactiver la 2FA** revient au code par e-mail si la
double authentification est exigée pour vous.

### Clés d'accès

**Ajouter une clé d'accès** enregistre une passkey (empreinte, visage, code du
téléphone ou clé de sécurité) sous le nom de votre choix. Vous vous connectez
ensuite sans mot de passe ni code. Supprimez une clé que vous n'utilisez plus.

### Appareils mémorisés

La liste montre les navigateurs pour lesquels vous avez coché « Se souvenir de
cet appareil » en saisissant un code reçu par e-mail : ils ne vous demandent plus
de code pendant 30 jours. **Oublier** retire un appareil ; **Tout oublier** les
retire tous. Faites-le si vous perdez un appareil ou l'avez utilisé sur un poste
partagé.

## Apparence

Choisissez le thème clair, sombre ou celui de votre système.

## Langue

Choisissez l'anglais ou le français. La langue s'applique à tout l'intranet, au
back-office M'City et à vos notifications.
