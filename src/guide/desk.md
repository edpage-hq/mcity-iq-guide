# Le bureau

L'intranet est ouvert à tout compte actif. Le menu de gauche réunit, sous
**Intranet**, votre bureau, les communications et les ressources ; sous
**Administration**, les fonctions de votre poste (absentes si votre poste n'en a
pas). **Voir le site** ouvre le site public.

Tout ce que vous voyez est filtré par votre [périmètre](./introduction#notions-a-connaitre).

## Mon bureau

La page d'accueil de l'intranet affiche :

- **Mon périmètre** : vos produits, zones et bureaux (« Tous les produits et
  toutes les zones » pour la direction) ;
- **Dernières communications** et **Ressources récentes** ;
- **Espaces produits** : un accès à chaque produit de votre périmètre ;
- des bandeaux d'alerte selon votre poste : nouveaux messages de contact à
  traiter, produits désynchronisés.

Si aucun poste ne vous est encore attribué, le bureau vous l'indique :
demandez à l'administrateur général de compléter votre compte.

## Communications

**Communications** liste les annonces qui vous concernent : celles adressées à
tout M'City, et celles ciblées sur votre poste, votre département, un produit,
une zone ou un bureau de votre périmètre, ou sur vous nommément. Chaque
communication indique son auteur, sa date et sa cible.

Une communication est rédigée dans une seule langue, choisie par son auteur.

## Ressources

**Ressources** réunit les documents, procédures, notes, contacts et liens
partagés. Filtrez par type ; ouvrez un lien ou téléchargez un document.

- Une ressource **générale** est visible de tous les comptes.
- Une ressource rattachée à un produit n'est visible que si votre périmètre
  couvre ce produit ; elle apparaît aussi dans l'espace du produit.

## Espaces produits

Chaque produit actif de votre périmètre a son espace. Vous y trouvez :

- les zones où le produit est présent ;
- les équipes responsables et leurs membres ;
- les communications et les ressources propres au produit ;
- **Voir la page publique** : sa landing page sur le site ;
- **Ouvrir le back-office** : son back-office, sans ressaisir vos identifiants.

Le bouton **Ouvrir le back-office** n'apparaît que si l'accès vous est accordé,
compte par compte ou parce que vous êtes membre d'une équipe responsable du
produit. Sinon, l'espace vous l'indique ; faites la demande à l'administrateur
général. Être dans le périmètre d'un produit ne suffit pas pour ouvrir son
back-office.

## Accéder à un back-office produit

1. Ouvrez l'espace du produit, puis **Ouvrir le back-office**.
2. Le back-office vous connecte avec votre compte M'City (bouton « Se connecter
   avec M'City » sur sa page de connexion, si vous y arrivez directement).
3. Si vous n'êtes pas encore connecté à M'City, la connexion M'City (et sa double
   authentification) vous est demandée d'abord.

Se déconnecter de M'City ferme aussi les sessions des back-offices ouverts depuis
cette session. Ce que vous pouvez faire dans un back-office dépend de votre poste :
pour Auticway, voir [Back-office Auticway](./auticway).
