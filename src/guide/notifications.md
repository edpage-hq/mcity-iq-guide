# Notifications

M'City IQ vous prévient de ce qui vous concerne : dans l'application et, si vous
le souhaitez, par e-mail. Vous n'êtes jamais prévenu de vos propres actions.

## La cloche

La cloche de l'en-tête affiche le nombre de notifications non lues et les dix
dernières. Elle se met à jour toute seule chaque minute.

- Cliquez sur une notification pour l'ouvrir : elle est marquée lue et vous mène
  à la page concernée.
- **Tout marquer comme lu** vide le compteur.
- **Voir toutes les notifications** ouvre la page Notifications.

## La page Notifications

Elle liste toutes vos notifications, avec les filtres **Toutes** et **Non lues**,
et un lien vers les **Réglages**. Les notifications s'affichent dans votre langue
de travail. Celles lues depuis plus de 90 jours sont supprimées automatiquement.

## Ce qui vous est notifié

| Événement                | Qui est prévenu                                                                         | E-mail par défaut |
| ------------------------ | --------------------------------------------------------------------------------------- | ----------------- |
| Communications           | Les destinataires d'une communication publiée                                           | Non               |
| Ressources partagées     | Les comptes dont le périmètre couvre la ressource                                       | Non               |
| Messages de contact      | Ceux qui traitent les messages (PDG, Pôle Support, Support N1)                          | Oui               |
| Produits désynchronisés  | Le PDG et les membres des équipes du produit                                            | Oui               |
| Collecte des indicateurs | Après trois échecs de suite : le PDG et les équipes du produit                          | Oui               |
| Équipes                  | Le compte ajouté à une équipe ou retiré                                                 | Non               |
| Vos accès                | Le compte dont le poste, le département, le périmètre ou les accès back-office changent | Oui               |

Une alerte de produit désynchronisé apparaît aussi en bandeau sur le bureau.

## Choisir comment être prévenu

Dans **Paramètres → Notifications**, cochez pour chaque événement **Dans l'app**
et/ou **Par e-mail**, puis enregistrez. La liste ne montre que les événements
que votre poste peut recevoir.
