# API

The API lets a product's back-office read its record, update its access URL and
languages, and report its indicators.

## Conventions

- Base: `https://mcityiq.com/api/v1` (test: `https://mcity.edpage.net/api/v1`).
- JSON, `camelCase` fields, UUID identifiers, ISO 8601 dates in UTC.
- Limit: 60 requests per minute per token.
- Every response carries an `X-Correlation-Id` header. Quote it when reporting a
  problem.

## Authentication

```http
Authorization: Bearer mcity_<48 characters>
```

The service token is generated by the CEO on the product's **API integration**
page. It is shown only once and stored hashed; generating a new one revokes the
old one. A token acts only on its own product: any other ID answers 404.

Missing or unknown token: 401, `WWW-Authenticate: Bearer` header, body
`{ "message": "Invalid service token." }`.

## Errors

```json
{ "message": "...", "errors": { "field": ["..."] }, "correlationId": "..." }
```

| Code                  | Meaning                                                   |
| --------------------- | --------------------------------------------------------- |
| 200 / 201 / 202 / 204 | Success                                                   |
| 400                   | Malformed request                                         |
| 401                   | Missing, expired or invalid token                         |
| 403                   | Valid token, action outside its rights                    |
| 404                   | Resource doesn't exist or is outside the token's scope    |
| 409                   | Stale `version`                                           |
| 422                   | Business rule broken (unknown indicator key, for example) |
| 429                   | Rate limit exceeded                                       |
| 500                   | Unexpected error, logged with the `correlationId`         |

## `GET /products/{id}`

Reads the product's record, e.g. to reconcile after an outage.

```json
{
  "productId": "7d3a…",
  "version": 4,
  "name": "Auticway",
  "status": "active",
  "accessUrl": "https://auticway.example",
  "supportedLanguages": ["en", "fr"],
  "zones": [{ "id": "b2f1…", "name": "Ho", "region": "Volta", "zoneType": "growing_city" }],
  "updatedAt": "2026-09-22T10:05:00Z"
}
```

It is the record sent by the [webhook](./webhook), without `event` or
`occurredAt`.

## `PUT /products/{id}`

Updates the record from the product. The product changes only:

- `accessUrl`: a URL, or `null`;
- `supportedLanguages`: lowercase ISO 639 codes (2 or 3 letters), 20 at most.

A missing field stays unchanged; any other field is ignored. The rest of the
record belongs to M'City.

```json
{ "version": 4, "accessUrl": "https://auticway.example", "supportedLanguages": ["en", "fr", "pt"] }
```

The `version` read is required. If it is no longer the current version, the
response is 409: read the record again, then retry. On success, the response is
the full record with the `version` incremented. The change is logged and is not
sent back to the product by webhook.
